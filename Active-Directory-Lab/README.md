# Active Directory Lab – On-Premises Environment

This repository showcases a hands-on **Active Directory lab project** simulating a small enterprise network using VirtualBox. The lab provides practical experience in deploying and managing a Windows-based domain environment with centralized identity, security, and automation. Ideal for learners preparing for IT certifications like **CompTIA Network+**, **Microsoft Certified: Azure Administrator**, or **MCSA equivalents**.

---

## Lab Overview

The lab demonstrates real-world IT administration scenarios in a safe, isolated virtual environment. Key objectives include:

- Deploying and configuring a Windows Server Active Directory domain.
- Managing users, groups, organizational units (OUs), and permissions.
- Joining client machines to the domain and testing logins.
- Automating administrative tasks using PowerShell.
- Implementing Group Policy Objects (GPOs) and logon scripts.
- Centralizing file storage with home directories and folder redirection.

**Completion Date:** September 29, 2025  
**Estimated Duration:** 4–6 hours  

---

## Core Accomplishments

- **Virtualization:** Configured VirtualBox VMs with NAT networking for isolated testing.  
- **Active Directory:** Installed AD DS, created a domain (`lab.local`), managed OUs, users, groups, and role-based access.  
- **Client Integration:** Joined Windows 10 client to the domain and tested logins.  
- **Group Policy:** Created GPOs for mapped drives, security restrictions, and logon scripts.  
- **File Services:** Configured shared folders, NTFS permissions, home directories, and folder redirection.  
- **Automation & Security:** Used PowerShell scripts and snapshots to automate tasks and maintain secure configurations.  

---

## Skills Demonstrated

- **Technical:** Virtualization, Windows Server administration, Active Directory management, GPOs, NTFS permissions, PowerShell scripting, network configuration, DNS troubleshooting.  
- **Professional:** Problem-solving, documentation, project planning, adherence to best practices, and portfolio-ready lab reporting.

---

## Key Insights

- DNS configuration is critical for Active Directory functionality.  
- Automation via PowerShell enhances efficiency and scalability.  
- Snapshots allow safe experimentation and rollback of configurations.  
- Proper NTFS and share permissions prevent access conflicts.  
- Folder redirection centralizes user data and simplifies backups.

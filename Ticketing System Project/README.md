# Help Desk Project

## Overview
This project demonstrates the setup and operation of a cloud-based IT help desk using **Jira Service Management as the primary platform**, with **Spiceworks and Freshdesk** included for additional exposure. It simulates a real-world IT support environment and covers the full ticket lifecycle, from request submission to resolution and closure.

The lab focuses on core help desk tasks such as ticket creation, categorization, prioritization, technician workflows, user communication, escalation, documentation, and basic reporting using dashboards and queues.

## Goals & Objectives
The goal of this project is to develop practical, job-ready help desk skills and demonstrate familiarity with modern IT ticketing systems and support workflows.

By completing this project, you will be able to:

- Configure and manage a help desk system, including projects, users, agents, ticket categories, priorities, and automation rules.
- Understand and apply ticket workflows, statuses, and prioritization to handle support requests efficiently.
- Submit, manage, and resolve tickets using email, user portals, and technician-created requests.
- Troubleshoot common hardware, software, network, and access-related issues using structured methods.
- Communicate clearly with users, document all actions accurately, and use internal notes effectively.
- Monitor ticket activity using dashboards and basic reports to identify trends and workload.

This project serves as both a **hands-on learning lab** and a **professional reference**, showcasing the technical and operational skills expected in entry-level IT support and help desk roles.
